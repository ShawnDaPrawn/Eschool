# Profile details

Open **Settings → Profile details**. The form uses your school's categories,
labels and privacy rules. Read-only details appear as text. Save updates only
the fields you changed; a failed save keeps your entries for correction.

If you belong to several schools, choose the person and school above the form.
Guardians can choose an authorised child there too. That selection applies to
the profile form. The school is shown beside the person's name.

Switching people, changing profile type or refreshing asks before discarding
unsaved edits. Private drafts stay in the open screen's memory. Save before
leaving the screen. Schools still using an older server will see this setting
when the profile endpoint becomes available.
