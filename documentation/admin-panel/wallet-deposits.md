# Parent wallet deposits

Parents open **Wallets → Parent wallet deposits** after paying the school by cash
or EFT. Enter the actual method, amount, receipt reference and paid date, add
private proof, review and submit. A request does not increase the wallet balance.
Keep the WD request reference. Withdrawing a pending request moves no bank or
wallet money.

Finance chooses supported methods under **Money → Parent wallet deposits**.
These settings are separate from school-owned master funding. Both may be set to
No to pause parent deposits while existing internal transfers continue.

A different Finance operator checks the outside receipt and original holder,
corrects mistaken details, confirms receipt and credits that parent's wallet.
The WP receipt and balance reflect the actual verified amount; the original
request remains visible. Money never enters the school master. Cash verification
records the operator who received and holds it.

Finance can reject with a safe outcome and private review note. Private proof
never appears on the printable receipt. Disabled wallets retain readable history.
Resolve interrupted app requests after reopening before submitting another claim.
No payment gateway is involved.
