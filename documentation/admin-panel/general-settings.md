# General Settings

These settings will be used by Admin Panel. You can set your current session year here.

On the branding card, write the school's privacy notice and terms in the school's own words. Parents accept NavigateEd's terms when they sign in, then these. Leave a page blank if you do not need it. Saving a change asks every parent to accept again. The same text is used on the public Privacy Policy and Terms pages.
