# Profile fields

Open **Settings → Profile fields** and choose a profile type. Add a category,
then a field with a permanent key, label, type and order. Choose who may see or
edit it. Only your current school's forms change.

Locked NavigateEd defaults keep their type and protection. You can arrange
fields and narrow access. You cannot remove a populated choice or retype a
populated field; clear the affected values first. Hide or restrict a field when
it should no longer be offered.

Open **Person profile** from the learner list, or **Settings → My profile** for
your own details. Save only the fields you changed. Missing information in
other fields does not block that save. A failed save keeps your entries on the
open page. Private entries are not saved as browser drafts; save before leaving.

**Export permitted fields** downloads the fields you may export. Sensitive
fields also require the explicit sensitive-export permission. Staff access to a
learner profile depends on their assigned learners or profile permissions.

The older extra-field forms and their stored values are being migrated in a
separate change. File fields are not offered in this editor yet.
