# Reissuing invitations

An emailed invitation belongs to the email address it was sent to. If a guardian's
address changes, verify the new address through a new invitation. The previous
link cannot verify it. Removing a guardian or their approval rights also ends
their ability to set a learner's password through an old link.

After the invitation mailbox-binding upgrade, reissue outstanding emailed
invitations. Existing printed setup codes retain their usual expiry and one-use
behaviour. A new printed code replaces the previous code.

Choosing a learner password does not approve the learner's access. A verified,
authorised guardian still makes that separate approval decision.
