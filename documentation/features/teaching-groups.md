---
title: Teaching groups and allocations
---

In **Academics → Teaching groups**, map each existing class to its grade reference.
Create a group for a subject, grade and school year. Associate one homeroom or
choose mixed homerooms. Class names are never used to guess grades.

Add learners with start/end dates and the school's catch-up, excused or carried
mark rule. A dated enrolment in that grade must cover the entire membership.
Then allocate one or more teachers with effective dates. A future allocation lets
teachers prepare curriculum; actual capture requires an effective assignment.

**Academic allocations** records homeroom teachers and appointments for grade
heads and principals. Grade heads have one grade/year scope; principals have a
year scope. Only authorised school staff can make or correct appointments.

Use **Correct effective dates** to end or correct an assignment with a reason.
Each correction is audited and a stale edit returns a conflict. Existing group
context stays fixed, and used class-grade mappings are protected to retain history.
Create a new group/class when its academic context changes.

Existing app assignment fields remain available through current dated projections.
Their IDs remain stable, and expired assignments cannot retain access if the
scheduled projection refresh is delayed. Edit the canonical dated allocation,
not its older projection. Learner marks are never created or copied by assigning
a group; capture, moderation and subject-change rules are separate workflows.
