# Weekly learning updates

A Parent opens **Weekly learning update** from home after selecting a child. The
latest available week opens first. Choose an earlier week or change the preferred
language for future updates. The home instruction opens the relevant school
record or published learning material in one tap. Updates contain only that
child’s school evidence, and clear when the app goes into the background.

A school manager enables the Digest module, opens **Weekly digest templates**,
and drafts the title, summary, generic notification and four home instructions
in each language the school supports. Review all wording before selecting
**Approve this language version**. Starting text is English and unapproved.
Create another version to change wording; **Withdraw language approval** also
withdraws existing updates using that version. A language awaiting approval
never silently switches to another language. Other approved languages continue.

The scheduler composes the previous Monday–Sunday evidence after 07:00 local
Monday. Updates are retained for at most 26 weeks. Missing or withdrawn family
access removes the update and its notification. Staff managers maintain wording
without receiving family summary access through the manager page.
