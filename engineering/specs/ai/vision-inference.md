# Private feature vision boundary

Vision is available only through a registered feature policy plus a separate server-owned media resolver. Generic staff calls cannot pass images, URLs or inline bytes. The feature policy authorizes ownership, school, subject, operation and immutable source references before retrieval; its resolver must repeat the concrete private Files and crop-approval checks before loading any pixels. The gateway compares the resolved manifest exactly with the authorized request and repeats authorization around moderation and inference. Replay requires those same live source checks.

The manifest contains text and at most three opaque `{id, sha256, mime}` references. Only private pixel-only PNG derivatives up to 32 KiB and 1,024 pixels per edge are accepted. PNG checks validate length, CRC, dimensions, decodability and an IHDR/IDAT/IEND chunk allowlist before dispatch. Provider payloads contain bounded inline data; there is no remote image fetch or original filename. The original request, usage receipt and quarantine snapshot never contain image bytes.

The crop helper requires an explicit approval and a bounded working-area rectangle, creates a fresh pixel canvas and removes metadata. This is not OCR or automatic visible-identifier detection. A crop can exclude a visible name outside the selected working region; it cannot prove that text remaining inside the approved crop is anonymous. The concrete Tutor upload must persist the approved crop/hash/operation and reject missing or stale approval. Image/privacy qualification remains disabled until that complete feature is qualified.

Each image reserves a conservative 8,192 input-token allowance in addition to text, system and maximum-output allowances. All allowances enter existing school/actor/learner budgets, usage validation and the same overall feature deadline. An unavailable or unqualified adapter fails preflight without inference charges; an unknown post-dispatch outcome retains conservative charging.

OpenAI and Anthropic use their bounded image protocols; OpenAI moderation inspects text and images before inference and text after inference. DeepSeek remains text-only. Existing fixed-origin transport, no redirects, single attempt, response bounds and anonymous metadata stay in force. New code does not enable inference, register a live learner feature, provision credentials or qualify a provider. HTTP protocol fixtures establish software behavior, not real-model safety, privacy, cost or latency acceptance.
