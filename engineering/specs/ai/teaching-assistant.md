# Teaching assistant and test insights

The independent `teaching_assistant` and `test_insights` modules default off.
Only currently allocated staff can create and read their private drafts, in the
current school/year; generic admin, platform and impersonation access grant no
bypass. The current group's published content and exact immutable source hashes
constrain generation. Lesson materials and worksheets contain support, core and
extension sections; practice questions use the existing approved practice answer
format. A report comment uses only the chosen learner's authorized marks and
teacher-visible guidance; counselling and safeguarding material are excluded.

All generation uses the registered AI gateway purpose, prompt versions,
moderation, metering and existing school/actor/learner caps. Real inference stays
disabled and no provider qualification or spend is implied. Cropped script
photographs use a separately authorized private derivative; a client path cannot
select another feature's image. Suggested question marks retain confidence and
source fingerprints as proposals, and never change official marks automatically.

A teacher edits a bounded draft, then explicitly approves or discards the current
revision. Immutable operation IDs preserve uncertain outcomes; changed bodies or
stale revisions conflict. Student practice receives an item only through the
existing explicit `PracticeBank::approve` operation. Sharing lesson materials or
copying a report comment uses the existing publication/release authority. Every
read and approval rechecks allocation and exact current source authority.

Task insights compute most-missed questions from current canonical question
marks, without learner identities in aggregate provider context. A school job
refreshes the affected task snapshots after mark changes. Likely misconceptions,
a re-teach pack and a follow-up quiz remain staff-only suggestions requiring the
same explicit edit/approval steps. Missing question evidence stays unknown.

Required verification covers wrong role, school and owner; source/allocation and
module withdrawal before/after provider I/O and replay; output quarantine and
retention; exact UUID recovery; draft editing/approval/discard and no automatic
mark publication; bounded aggregate statistics and stale source replacement.
Teacher and dedicated Facilitator clients must be exercised in an actual browser
and at phone/desktop widths before their completion is claimed.
