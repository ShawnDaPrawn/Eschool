# Discipline apps

Staff can browse their dated, authorized records, capture factual entries, inspect retained revisions, submit reasoned grade-head reviews and handle separate principal hearings. Detention supervisors select a learner before capturing attendance; cancellation and correction drafts remain separate. Framework configuration and detention planning remain available in the panel.

Learners and current guardians use only the published family projection. Guardians acknowledge the exact published revision; learners cannot acknowledge. The first family request omits the year and receives authorized history years. It never requests staff configuration or another child’s records.

The shared readers pin account, school, token and context before and after calls. Private requests suppress URL logging. Every context refresh remounts readers, including identical profile payloads; backgrounding and withdrawn roles, modules or guardian links erase private bodies. Missing writable capability is read-only. Unknown writes retain immutable exact retry intent; a confirmed write followed by a failed refresh remains confirmed. Unsaved drafts require explicit discard.

The dedicated facilitator Teacher card requires the fresh discipline capability and does not initialize classic Teacher authentication or clinical services. Existing support, counselling, recognition and private-inbox entries remain intact. English fallback labels preserve existing translations; fluent translation acceptance is separate.
