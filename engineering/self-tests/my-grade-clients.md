# My grade app workbench

Classic Teacher and the dedicated Facilitator shell now open the existing
current-year grade-head dashboard. Teacher Home, Settings and the deep route
require the fresh module/capability; the dedicated profile computes its capability
from the same dated academic appointment. No new grade-head role is introduced.

The shared workbench shows attendance follow-up, academic watch and the discipline
queue, with grade-parent messages, existing intervention and nomination readers.
It opens the exact discipline record, rechecks the appointed grade before nested
actions and uses the current dated homeroom register. Register sync retains the
existing encrypted owner-bound pending-operation store and exact UUID replay.
Only a current head can preselect the grade's parents in the message editor.

Private requests pin both account and school, check the captured bearer/context
epoch before and after HTTP and never persist dashboard data. Backgrounding hides
private editor controls while retaining an uncertain operation; a fresh grade/year
check is required before showing them again. A changed account/school/profile
permanently invalidates that reader, including late successful responses.
