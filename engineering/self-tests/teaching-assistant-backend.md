# Teaching assistant backend and typed contract

The private teaching-draft/task-insight domain, fifteen HTTP operations, typed
SDK and approved-copy PDF export are implemented. Teacher and dedicated
Facilitator app screens are a separate follow-on; this record does not claim
those UX or browser acceptance checks.

## Verified behavior

Current school, dated teaching allocation and the original draft owner constrain
reads, edits, approvals, receipts and exports. Parent, Student, generic admin and
platform roles grant no bypass. Source fingerprints are checked before/after
provider I/O and on every review. Reports exclude counselling context and minimize
the selected learner's identifying text. Three-level worksheets/lessons, report
comments, practice/follow-up questions, re-teach packs and script proposals use
the registered gateway purpose, moderation and conservative metering.

Approval preserves a private draft. Practice publication and application of
script proposals to official marks require separate confirmed actions. Unknown
question marks block confirmation until human review; official marks retain the
canonical optimistic revision check and audited writer. Unknown dispatched AI
outcomes retain the original operation UUID and conservative charge, without an
automatic second compute. Exact review/revocation retries recheck fresh authority.

Script photographs require explicit crop approval and scanning of both raw and
sanitized pixels. Retained derivatives are bounded, metadata-free and encrypted.
Quarantine withholds bodies and permits derivative reads only through explicit
safeguarding snapshot authority. Unused crops expire after seven days and drafts
after ninety days, before a late pruning job. Bounded orphan reconciliation only
removes recognized expired derivatives in the current school's namespace. The
usage ledger and human-approved official records remain intact.

Insights use current canonical question evidence and the current roster. Missing
evidence stays unknown. Refresh jobs do not generate AI; aggregate provider
context has no learner identities. Approved PDF copies recheck source authority
after rendering, disable remote resources/embedded PHP, restore the app locale,
and omit practice answers unless explicitly requested for the teacher copy.

## Evidence

Drafts, insights and the complete OpenAPI response/scenario cohort passed
**515 tests / 2,557 assertions**. A further scoped orphan-reconciliation regression
passed **1 test / 5 assertions**. These include real HTTP generation, original
receipt recovery, exact approval replay, private crop preview/revocation,
approved PDF output and source withdrawal. All fifteen routes reject anonymous
requests with private errors. Domain cases cover wrong owner/school/role,
allocation changes during moderation and after compute, clinical minimization,
unknown compute, quarantine, retention and official-mark protection.

The capability-inclusive SDK generated **2,046 Dart files identically twice**;
all **133 SDK tests** passed. The contract adds fifteen operations and thirty-five
schemas; every existing path/schema was compared structurally before insertion.
Two optional Facilitator capability fields have no defaults and grant no roles;
availability checks fresh teaching allocation and module authority. Final
combined schema/capability validation is recorded in the PR.

Strict OpenAPI lint, whole-application PHPStan and Pint passed during backend
qualification. The exact published integration head still requires full CI.

## Remaining acceptance

flows belong to the app follow-on. Both modules and external inference default
off. Protocol fakes do not establish provider safety, live-model red-team rates,
cost, response latency, fluent wording or independent safeguarding acceptance.
No provider, production deployment or store release was activated.

the full teaching-draft/insight cases, Exam Coach domain, family consent domain,
