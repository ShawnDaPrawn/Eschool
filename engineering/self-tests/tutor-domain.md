# Tutor domain qualification

The domain implements subject sessions, encrypted turns/context, immutable current source policy, private scanned/cropped photo storage, feature moderation, provisional feedback and deterministic parent learning metadata. It does not yet expose public HTTP/app flows; those are the next increment. No pilot requirement or broad staff chat grant is introduced.

Native PHP/MySQL qualification: combined Tutor/AI/vision/provider cohort **70 tests / 463 assertions** passes. A further focused boundary cohort passes **6 tests / 25 assertions**, covering five additional unique Tutor cases plus the source-withdrawal regression. There are **19 unique Tutor domain cases**. Real schema inventory and tenancy rollback/backfill rehearsal pass **4 tests / 1,081 assertions**. Full configured PHPStan reports no errors and changed-file Pint passes.

Coverage includes exact session/turn retries, encrypted bodies, hints before working, provisional correction without official marks, wrong subject/extra-answer quarantine, tutor-only notes and known identifier minimization, wrong role/school and independently approved wrong owner, current guardian/source/author withdrawal, explicit crop approval and visible-name pixel exclusion, encrypted operation-bound photos, changed bytes/revocation refusal, source-only metadata quarantine, local safeguarding routing with inference disabled, retention without FK linkage or module access, unknown-outcome charging, simultaneous request refusal, crash recovery from the original gateway receipt, independent learner caps/read-only mode and parent summaries without dialogue/safety counts.

All provider responses/scanner results in these tests are explicitly synthetic protocol fixtures. They establish software behavior, not live-model refusal/privacy/safety, live scanner readiness, latency, provider cost, multilingual safeguarding or physical camera acceptance. The registered feature remains disabled; no default model/rate is invented. Concrete API/SDK/shared app, approved exercise outcome integration and real provider qualification remain outstanding.
