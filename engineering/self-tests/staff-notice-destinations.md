# Dedicated staff notice destinations

Progress alerts now open the existing allocated academic progress/notes reader
for a fresh Teacher profile. Discipline alerts open the existing source-scoped
discipline screen when its fresh capability remains available. Requests keep
the expected school/account binding and generation guard. Existing consultation
and wellbeing actions remain present. No Teacher/Firebase/legacy auth bootstrap
or counselling grant is added to the dedicated staff shell.

Five widget cases pass at 390px and 1280px, including progress note access,
discipline follow-up, withdrawal erasure, expected headers and a stale progress
item after Teacher-role removal. The new 390px flow proved a 61px dropdown
RenderFlex overflow; bounded expanded dropdowns resolve it. Selected analysis
has zero errors/warnings; formatting passes.

Actual dedicated-flavour Chrome qualification is **pending**. The prepared
integration target is facilitator_progress_notice_smoke_test.dart, with both
progress and discipline entrypoint flows, scoped headers, withdrawal erasure
and authBox-closed assertions. The coordinating agent will run it alongside
Teaching Assistant in the combined Fac build. This source PR remains draft
until that actual evidence is recorded; no browser pass is claimed here.
