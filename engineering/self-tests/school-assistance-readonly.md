# Read-only school assistance

The configuration emits an optional, no-default writable boolean. A read-only
ask_school switch preserves current authorised document and thread reads while
refusing writes; installed clients may ignore the additive field.

The actual typed HTTP regression passed 1 test / 26 assertions, including existing
private reads, false capability and refusal to append a reply. The six assistance
SDK protocol tests pass, including absence versus explicit false. Both pinned
regenerations produced byte-identical hashes for all 2,402 source/manifest entries
(2,401 Dart files; no new model or operation). Pint passes. This is a narrow API
capability fix; Parent/office screen qualification is recorded separately.
