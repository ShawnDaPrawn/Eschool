# Private gallery API and generated client

Ten typed operations cover scoped configuration, owned approved/pending family
pages, current group pages, private JPEG variants, multipart upload, tag proposals,
revisioned guardian decisions/removal, asset withdrawal and school consent rules.
Private responses include success and refusals. No storage paths or public image
URLs are returned. Source authorization precedes caption and pixel retrieval;
the new configuration carries account/school/year identity for client leases.

The guardian transfer projection offers a private selection fingerprint only for
its current named guardian consent. Keeping photos is an optional explicit input;
old clients omit it and retain the original remove-on-transfer behavior. Private
choice failure does not block the independent academic workflow. A real HTTP
consent followed by atomic academic completion verifies the copied family scope.
