# Tutor topic and verified-checkpoint clients

The Student Tutor now offers optional current published-topic selection. Topic
sessions show a separate approved check with an immutable first attempt and
explanation only after the deterministic result. The card never invokes a model
or posts an official mark. Disabling inference keeps approved checks usable;
disabling daily practice leaves the existing conversation independently readable.

Submitted answers use the shared fifteen-minute scoped encrypted in-memory
intent. Backgrounding erases the rendered question and input. A fresh source
read is required before opening a retained answer, and uncertain receipt 404s
keep the original issue/answer UUID. Fresh 403 denial closes the retained body;
404/409 removes private rendered content. A known 422 permits correction.

All **30** selected new/existing Tutor repository, screen and session tests pass.
The nine new cases cover topic pinning, inference-off/practice-off independence,
first-attempt explanation withholding, exact lifecycle/404 recovery, fresh source
denial, school/account/session/checkpoint response binding, premature-answer
refusal and context withdrawal before HTTP. Source and the combined Family
browser target analyze with zero errors or warnings (existing style information
only). Every offered language receives explicit English fallback labels without
overwriting existing translations.

The actual combined Family Chrome run passes all three journeys. The Tutor
journey selects a published topic, starts an approved check with inference off,
withholds its explanation, recovers the exact first-answer UUID/body after an
uncertain response and backgrounding, displays its verified result and erases
private content after fresh source denial. No chat/model or official mark route
is called. Structured per-journey results record this as passed independently
of the Student Exam and Parent denial journeys in the same build.

Software/client verification does not claim physical-device, real-provider or
production acceptance. External inference remains separately disabled/qualified.
