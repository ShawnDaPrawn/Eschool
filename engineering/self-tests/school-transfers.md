# School transfer domain evidence

Eighteen domain, two-school isolation, school-owned table catalogue and actual
migration tests pass with 833 assertions. Full configured Larastan and Pint pass.

The round-trip preserves the global identity, closes the source enrolment and
opens the destination on the agreed date in one transaction. It retains source
released marks as historical evidence without creating local assessed marks or
activating an unapproved learner. An injected receiver failure rolls back both
schools. Named verified guardian consent, withdrawal, fingerprint and signature,
expiry, current source authority, changed enrolment, platform exclusion and
third-school overlap are covered. Routing-column tampering is rejected against
the signed manifest without revealing a third-school identity.

Actual generated report PDF bytes, a current document visible to both sender and
guardian, released marks and attendance are carried in an independently verified
signed ZIP. An interleaved same-operation retry cannot overwrite the adopted
archive. Source expiry and orphan cleanup preserve the receiving school's copy.
Repeated departures are rejected; historical external exports cannot end a newer
place. Global approval remains unchanged. Fixtures and documents are synthetic.

This is domain evidence. HTTP routes, browser and parent-app consent, notification
and device acceptance remain subsequent work; this record does not certify them.
