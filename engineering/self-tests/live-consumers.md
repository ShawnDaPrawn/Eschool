# Visible group and consultation live consumers

Activity readers subscribe to their explicitly authorized group while open,
show a distinct-person online count, refetch protected detail after invalidation
and leave presence when the reader closes. HTTP presence supplies the initial
count so a subscription/publish race does not leave an empty display. Known
current source refusal erases the group body and capture fields. Dirty or open
captures retain their draft and offer a guarded update prompt instead of being
replaced by an arriving event.

An open public poll results view refetches only its own aggregate reader. A
reconnection refreshes current permission before rendering private content again;
existing anonymous ballot drafts are preserved when still authorized. Wrong-poll
references cannot trigger an unrelated result fetch, and refused current access
erases the aggregate body. Socket messages supply no displayed record content.
